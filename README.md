# admiraldog
A simple computer with a R32i core and a character based VDC. 
Developed to be both available as an emulator (emulates R32i at instruction level) and in future even deployable to FPGA

## How to Build

See [README-DEVEL.md](README-DEVEL.md).

## Code Style

For the emulation and framework part we are usign a minimal subset of C++ (C++20), on the RTL part we will use System Verilog.

## Artificial Intelligence

A.I. and Agents will be used for exploring, setting up system tests and refactoring. Code will be on the other hand written by hand.
